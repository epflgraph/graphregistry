You are enriching metadata for one lecture using OCR text and automatically detected Wikipedia-style concepts from its keyframes.

Input:
- lecture_id: the lecture identifier.
- keyframes: a sequence of lecture keyframes.
- Each keyframe has:
  - keyframe_id: keyframe/keyframe identifier.
  - ocr_content: OCR text extracted from the keyframe.
  - concepts: candidate concepts detected from the OCR. These may contain false positives.

Tasks:

1. Infer a lecture title and descriptions from the whole lecture.
- title: concise, less than 60 characters.
- long_description: one paragraph, no line breaks.
- medium_description: about 3 lines worth of text, but still no line breaks.
- short_description: exactly in the style "Lecture on subject 1, subject 2, subject 3".

2. Produce the lecture-level top concepts.
- Put them in top_concepts.ai_refined_list.
- Return 10 to 20 concepts.
- Prefer exact Wikipedia page titles when appropriate.
- Do not include noisy UI/application terms such as PowerPoint, Acrobat, Zoom, Gmail, browser menus, timestamps, filenames, or OCR artifacts.

3. Refine the concepts for each individual keyframe.
For each input keyframe:
- Preserve the same keyframe_id.
- Compare ocr_content with the candidate concepts.
- Remove concepts that are likely fuzzy false positives.
- Add important missing concepts that are clearly supported by the OCR.
- Put the final keyframe concepts in refined_concepts.ai_refined_list.
- Leave raw_unrefined_list and post_validated_list empty unless you have a specific reason to fill them.

Important:
- Return only the structured output requested by the API schema.
- Do not invent lecture content unsupported by the OCR.
- Descriptions must not contain line breaks.
- Use the same lecture_id as the input.
